# AI Lead Qualification Chat Widget (ai-lead-qualifier)

An AI-powered inbound sales development representative (SDR) widget and operator dashboard built for the **FlyRank Frontend AI Engineering** track. It engages website visitors in real time, extracts **BANT** qualification signals (**B**udget, **A**uthority, **N**eed, **T**imeline), computes a live lead score (0-100), and exports structured JSON payloads for CRM routing.

## Key Features
- **Live BANT Signal Extraction**: Automatically detects budget tiers, decision-making authority, core pain points, and implementation timelines.
- **Dynamic Lead Scoring**: Classifies visitors into Cold, Warm (MQL), or Qualified (SQL) with visual progress bars.
- **Operator Telemetry View**: Real-time JSON payload inspector, one-click demo personas, and CRM export.
- **Accessible by Design**: Built with semantic HTML, aria-live chat logs, and full keyboard navigation.

## Quick Start
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
